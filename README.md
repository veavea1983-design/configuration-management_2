# Анализатор зависимостей Ubuntu apt

Практическая работа №2 по дисциплине
«Конфигурационное управление».

Вариант №3. Язык реализации: Python 3.

## Назначение

Программа предназначена для анализа зависимостей
пакетов Ubuntu и их визуализации.

## Этап 1. Конфигурация

Реализовано чтение настроек из INI-файла,
проверка параметров и вывод ключ-значение.

## Настройки

- `package` — имя анализируемого пакета.
- `repository` — URL репозитория или путь к файлу.
- `test_mode` — режим тестового репозитория.
- `version` — версия пакета.
- `output` — имя выходного PNG-файла.

## Структура проекта

- `src/config.py` — чтение и проверка INI.
- `src/main.py` — запуск приложения.
- `tests/test_project.py` — автоматические тесты.
- `config.ini` — настройки.
- `run.bat` — запуск на Windows.

## Запуск

```bash
py src/main.py --config config.ini
```

Или через `run.bat`.

## Тестирование

```bash
py -m unittest discover -s tests -v
```

## Основные функции

- `read_config()` — чтение конфигурации.
- `validate()` — проверка параметров.
- `parse_cli()` — чтение аргументов запуска.
- `main()` — запуск программы.

## Пример вывода

```text
package: bash
repository: https://archive.ubuntu.com/ubuntu/dists/noble/main/binary-amd64/Packages.xz
test_mode: False
version: 5.2.21-2ubuntu4
output: output/bash.png
```

На первом этапе реализована только конфигурация.
```

## Этап 2. Сбор данных

Реализовано получение индекса пакетов Ubuntu
по URL без использования менеджера apt.

Поддерживаются индексы `Packages.xz` и `Packages.gz`.

### Основные функции

- `download_index()` — скачивание и распаковка индекса.
- `parse_stanzas()` — разбор записей пакетов.
- `dependency_names()` — получение имён зависимостей.
- `get_direct()` — чтение Depends и Pre-Depends.
- `select_version()` — выбор указанной версии пакета.

### Запуск

```bash
py src/main.py --config config.ini
```

На втором этапе программа выводит
прямые зависимости указанного пакета.

При наличии альтернативных зависимостей
выбирается первый вариант.

## Этап 3. Граф зависимостей

Реализован алгоритм BFS с рекурсией для
построения графа транзитивных зависимостей.

### Основные функции

- `recursive_bfs()` — обход графа по уровням.
- `load_test_graph()` — загрузка тестового графа JSON.
- `apt_provider()` — получение зависимостей Ubuntu.
- `make_provider()` — выбор источника данных.

Для предотвращения повторной обработки пакетов
используется множество `visited`.

### Тестовый режим

Поддерживаются тестовые репозитории с именами
пакетов из заглавных латинских букв.

Подготовлены три графа:

- `graph_chain.json` — общие зависимости.
- `graph_cycle.json` — циклические зависимости.
- `graph_independent.json` — независимые ветви.

### Запуск

```bash
py src/main.py --config config_test.ini
```

Программа выводит полный граф зависимостей,
включая транзитивные зависимости.

## Этап 4. Порядок загрузки зависимостей

Реализовано определение порядка обработки пакетов
с учётом их зависимостей.

### Основные функции

- `loading_order()` — формирует порядок зависимостей.
- `visit()` — обходит зависимости выбранного пакета.

Алгоритм сначала обрабатывает зависимости пакета,
а затем добавляет сам пакет в итоговый список.

Повторная обработка предотвращается множеством
`done`. Для обнаружения циклов используется `active`.

### Запуск

```bash
py src/main.py --config config_test.ini
```

### Пример результата

Для графа `A -> B, C`, `B -> D`, `C -> D`:

```text
A: B, C
B: D
C: D
D:
Оценочный порядок: D -> B -> C -> A
```

### Сравнение с Ubuntu apt

Для сравнения используются команды:

```bash
apt-cache depends bash
apt-get -s install bash
```

Программа рассчитывает порядок по графу зависимостей.
Менеджер apt дополнительно учитывает версии,
альтернативы, виртуальные пакеты и состояние системы.

Поэтому рассчитанный порядок может отличаться
от плана установки, сформированного apt.
